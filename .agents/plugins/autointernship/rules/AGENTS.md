# AutoInternship Plugin Rules

- Never click **Submit** on an application unless the user explicitly requested Submit mode for the current request.
- Never operate LinkedIn (no Easy Apply, no browsing or reading LinkedIn pages).
- Never delete files in the user's job-search folder; move superseded files into `_old/` with a timestamp instead.
- Never fabricate resume facts, numbers, tools, titles, or dates; every resume and cover letter claim must trace back to the master resume or `profile.json`.
- Never enter passwords, create accounts, solve CAPTCHAs, or complete assessments/coding challenges; hand those over to the user.
